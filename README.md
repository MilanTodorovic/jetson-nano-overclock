# Jetson Nano - CPU, GPU and NVDEC overclock
This is a fork for personal use. All changes aren't meant for the general public.  
There is a `patches` directory which contains the patches which were applied to this kernel. They are there for archival purposes. All are already applied to the code in this repository.  
The default branch provides an overclock to the CPU, GPU and NVDEC.  
The CPU will run at 2GHz stable, GPU at 1Ghz and the NVDEC at 844Mhz.  
These overclocks require a stronger power supply. Suggesting 5v 4a as a minimum. The maximum supported (as per some forum posts) is 5v 5a.
